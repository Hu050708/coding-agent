# 任务：修复配置优先级中的 falsey 值回归

`appconfig` 按照“命令行参数 > 环境变量 > JSON 配置文件 > 默认值”的顺序加载配置。
当前普通非空值的优先级正确，但合法的 `0`、`False` 和空字符串会被错误地当成
“没有提供”，从而回退到优先级更低的来源。

请修复配置合并逻辑。

要求：

- 只有值为 `None` 才表示当前来源没有提供配置。
- `retries=0`、`debug=False` 和 `label=""` 都必须能够覆盖低优先级来源。
- 保持现有 CLI 参数、环境变量名称、JSON 输出结构和优先级顺序不变。
- 至少增加一项覆盖 falsey 值的回归测试。
- 完成前运行完整测试套件。
