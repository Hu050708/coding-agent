# 任务：增加可重复的日志类别筛选

`expense_report` 读取 JSONL 支出记录并按类别汇总。请为 CLI 增加可重复使用的
`--category NAME` 参数，使用户可以只汇总一个或多个指定类别。

要求：

- `--category` 可以出现多次，任意一个指定类别匹配时都应保留该记录。
- 类别匹配区分大小写；重复参数不应重复统计。
- 不提供 `--category` 时，输出必须与当前版本完全一致。
- 指定不存在的类别时，输出 `count=0`、`total_cents=0` 和空的 `categories`。
- 保持现有 JSON 输出结构和字段含义不变。
- 至少新增一项针对类别筛选的测试，并在完成前运行完整测试套件。
