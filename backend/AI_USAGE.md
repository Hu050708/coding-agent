# AI 使用说明

本项目允许并如实记录 AI 辅助开发。

## 使用范围

- 解析考核要求并检查提交约束；
- 核实 DeepSeek 官方 API 的模型、thinking 与 tool-call 协议；
- 讨论架构、安全边界、错误策略和测试矩阵；
- 参与主要模块的实现与重构、测试补充、问题定位和交叉代码审查；
- 辅助准备演示任务和文档。

## 人工责任

作者确定最终需求、架构和取舍，运行并检查测试与真实 API 轨迹，理解项目中的每个模块，
并对仓库、演示和提交内容负责。AI 输出不被视为正确性证据；关键协议、安全边界和任务结果
均通过独立测试或人工复核验证。

## 运行时边界

ClearLoop 的历史管理、工具 schema、参数解析、本地执行、状态循环、预算、终止和错误处理均
由仓库代码实现。运行时仅使用模型厂商兼容的底层 API 客户端，不使用现成 Agent 产品、
Agent 框架、Agent SDK、服务端代码执行、服务端文件工具或 MCP。
