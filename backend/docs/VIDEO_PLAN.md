# 两分钟视频方案

目标时长 100–110 秒。画面只保留项目、命令和运行结果，不显示 API Key、`.env`、账户信息、个人目录或隐藏推理。

## 画面安排

### 0–15 秒：项目与架构

画面：根目录 README 的架构图。

讲解：

> Coding Agent 使用 DeepSeek 官方 API，但 Agent 循环由项目实现。模型选择工具，本地程序负责上下文、参数校验、权限、执行和终止。

### 15–30 秒：核心代码

画面依次定位：

- `agents/agent.py`
- `agents/providers/deepseek.py`
- `agents/tools/registry.py`
- `agents/security/workspace.py`

讲解：

> 适配器只完成一次模型请求；Agent 维护多轮历史。八个工具在本机执行，文件路径、命令和审批都由后端校验。

### 30–78 秒：真实任务

在 `backend/` 目录运行：

```powershell
python scripts/run_demo_trial.py
```

画面保留以下节点：

1. 读取任务和项目；
2. 搜索、读取目标代码；
3. 使用 SHA-256 修改文件；
4. 运行测试；
5. 根据失败结果修正；
6. 输出最终总结。

可压缩等待时间，但工具顺序、失败恢复和测试结果必须可辨认。

### 78–96 秒：独立验收

画面：verifier 输出或固定评测报告。

讲解：

> 模型 final 只代表运行结束。候选代码由 Agent 工作区外的 verifier 执行隐藏边界测试，模型不能修改验收程序。

### 96–110 秒：结果与边界

画面：测试数量、9/9 固定评测结果和安全边界。

讲解：

> 项目记录模型调用、工具调用、Token、耗时和终止原因，不保存隐藏推理。文件工具受工作区限制，但获准程序仍有当前运行账户权限，因此命令策略不是操作系统沙箱。

## 录制前检查

- 使用全新任务副本，不复用已经修改的目录；
- 先完成一次不录屏的完整演练；
- 确认 API Key 只在当前进程环境中；
- 关闭通知、密码管理器和无关窗口；
- 检查终端、浏览器地址栏和历史命令；
- 逐帧确认无密钥、`.env`、账户信息和隐藏推理；
- MP4 小于 2 分钟、200 MB；
- ZIP 根目录只包含 `README.txt` 和视频。

只有在最终提交上重新执行并通过的结果，才能作为视频中的当前结果展示。历史报告必须保留其提交号和试验日期。
